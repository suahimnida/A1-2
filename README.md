# 국내 여행 추천 프로그램

## 1. 프로그램 개요

Google Gemini API(`google-genai` 공식 SDK)와 카카오맵 로컬 API(키워드로 장소 검색)를 함께 사용해,
사용자가 입력한 날짜를 기준으로 국내 여행지를 추천하고 맛집 정보를 곁들인
여행 리포트를 자동으로 생성하는 CLI 프로그램입니다.

동작은 아래 3단계로 진행됩니다.

1. **1차 추천 (Gemini)**: 입력 날짜 기준 여행하기 좋은 국내 도시와 날씨/행사 정보를 JSON으로 생성
2. **맛집 검색 (카카오맵)**: 추천 도시 기준 맛집 최대 5곳 검색
3. **최종 리포트 생성 (Gemini)**: 위 결과를 종합해 Markdown 여행 리포트 작성

각 단계는 실행 중 진행 로그(`[HH:MM:SS] ...`)로 상태를 보여주며, 완료되면
결과 파일이 저장된 경로를 안내합니다. 맛집 검색이 실패하거나 결과가 0건이어도
프로그램은 중단되지 않고 "데이터 없음"으로 표기한 채 리포트 생성까지 이어집니다.

## 2. 실행 방법

### 2.1 사전 준비

```bash
pip install -r requirements.txt
```

Python 3.10 이상이 필요합니다.

### 2.2 실행 명령어

터미널(또는 VS Code 통합 터미널)에서 아래처럼 실행합니다.

```bash
python travel_recommender.py -date "2026-10-05"
```

- `-date` 옵션은 필수이며, `"YYYY-MM-DD"` 형식이어야 합니다.
- 날짜 형식이 올바르지 않으면 사용법을 안내하고 즉시 종료합니다.
- VS Code의 실행(F5) 버튼으로 돌릴 경우, `-date` 인자가 자동으로 전달되지 않아
  `error: the following arguments are required: -date` 오류가 날 수 있습니다.
  이때는 터미널에서 직접 실행하거나, `.vscode/launch.json`의 `"args"`에
  `["-date", "2026-10-05"]`를 추가하세요.

## 3. API 키 설정 방법

이 프로그램은 두 개의 키가 필요합니다.

| 환경변수 | 발급처 | 비고 |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio | 1차 추천 + 최종 리포트 생성용 |
| `KAKAO_REST_API_KEY` | Kakao Developers | 맛집(장소) 검색용 |

### 3.1 카카오 REST API 키 발급 및 활성화

1. [Kakao Developers](https://developers.kakao.com)에 로그인 후 애플리케이션을 생성합니다.
2. [내 애플리케이션] > [앱 설정] > [앱 키]에서 **REST API 키**를 복사합니다.
3. **반드시** [내 애플리케이션] > [제품 설정] > **카카오맵** 메뉴로 들어가
   "사용 설정" 상태를 **ON**으로 바꿔야 합니다. 이 설정이 꺼져 있으면
   키가 맞아도 `403 disabled OPEN_MAP_AND_LOCAL service` 오류가 발생합니다.

### 3.2 .env 파일로 설정하기 (권장)

프로젝트 폴더에 `.env.example`을 복사해 `.env` 파일을 만들고 값을 채웁니다.

```bash
cp .env.example .env
```

```
GEMINI_API_KEY=발급받은_제미나이_키
KAKAO_REST_API_KEY=발급받은_카카오_REST_API_키
```

`python-dotenv`가 설치되어 있으면 프로그램 실행 시 `.env`를 자동으로 읽습니다.

### 3.3 환경변수로 직접 설정하기

```bash
# macOS/Linux (현재 터미널 세션에만 적용)
export GEMINI_API_KEY="YOUR_KEY"
export KAKAO_REST_API_KEY="YOUR_KEY"

# Windows PowerShell (현재 세션에만 적용)
$env:GEMINI_API_KEY="YOUR_KEY"
$env:KAKAO_REST_API_KEY="YOUR_KEY"
```

키가 하나라도 설정되어 있지 않으면 프로그램은 즉시 종료되며,
콘솔에 위 설정 방법이 그대로 안내됩니다.

## 4. 결과물 확인 방법

실행이 끝나면 `results/` 폴더 아래에 실행 날짜 기준으로 파일 두 개가 생성됩니다.

- `results/YYYY-MM-DD_raw.json` — 1차 추천 JSON, 맛집 검색 결과(0건 가능), 오류 목록(`errors`)을 담은 원본 데이터
- `results/YYYY-MM-DD_report.md` — 추천 지역/이유, 날씨, 행사, 맛집 리스트, 1일 일정을 포함한 최종 Markdown 리포트

프로그램이 완료되면 콘솔 마지막에 두 파일의 **절대 경로**가 그대로 출력되므로,
그 경로를 복사해 파일 탐색기나 VS Code에서 바로 열어보면 됩니다.

```
============================================================
완료되었습니다! 결과물이 아래 경로에 저장되었습니다.
  - 원본 데이터(JSON): C:\...\results\2026-10-05_raw.json
  - 최종 리포트(Markdown): C:\...\results\2026-10-05_report.md
============================================================
```

## 5. API 키 유출 주의사항

- **API 키를 코드에 직접 작성하지 않습니다.** 이 프로그램은 `GEMINI_API_KEY`,
  `KAKAO_REST_API_KEY`를 항상 `.env`/환경변수에서만 읽어옵니다.
- **`.env` 파일은 절대 git에 커밋하거나 압축해서 제출하지 않습니다.**
  프로젝트에 포함된 `.gitignore`에 `.env`가 이미 등록되어 있으니,
  새로 프로젝트를 만든 경우에도 반드시 확인하세요.
- **README, 로그, 결과 파일(`results/*.json`, `*.md`)에도 키 값이 남지 않도록 주의합니다.**
  이 프로그램은 오류 메시지에 키 값 자체를 출력하지 않지만,
  터미널 화면을 캡처해서 공유할 때 `.env` 내용이나 키가 찍히지 않았는지 한 번 더 확인하세요.
- 키가 실수로 노출되었다면(예: 공개 저장소에 커밋, 캡처 이미지 공유 등)
  즉시 Google AI Studio / Kakao Developers에서 해당 키를 **폐기(재발급)**하세요.
  키를 교체해도 코드는 그대로 두고 `.env` 값만 바꾸면 되므로 운영에 지장이 없습니다.
- 카카오 API는 앱별 무료/과금 쿼터가 있으므로, 키가 유출되면 제3자가 내 쿼터를
  소진하거나 예상치 못한 과금이 발생할 수 있습니다. 정기적으로 키를 교체하는 것도 좋은 습관입니다.
